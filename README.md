# 🎵 AppSpotify - Clone de Layout

## 📱 Sobre o projeto

Este projeto foi desenvolvido como parte da avaliação de Android Studio, com o objetivo de reproduzir visualmente uma tela de um aplicativo famoso.

O aplicativo escolhido foi o **Spotify**, utilizando como referência a tela de **"Tocando agora"**.

O projeto apresenta uma interface inspirada no Spotify, utilizando o álbum **Verbalize**, da banda **Natiruts**.

> Este projeto é apenas um clone visual para fins educacionais. Não possui as funcionalidades reais do Spotify.

## 🎯 Objetivo

O objetivo do projeto é praticar:

- Desenvolvimento de interfaces no Android Studio;
- Criação de layouts com XML;
- Utilização do `ConstraintLayout`;
- Organização de elementos na tela;
- Utilização de imagens e recursos;
- Aplicação de cores e textos;
- Reprodução visual de uma interface existente.

## 🛠️ Tecnologias utilizadas

- **Android Studio**
- **Kotlin**
- **XML**
- **ConstraintLayout**
- **Android SDK 36**

## 🎨 Tela desenvolvida

A tela criada representa uma tela de reprodução de música, contendo:

- Nome "Tocando agora";
- Capa do álbum;
- Nome do álbum;
- Nome do artista;
- Barra de progresso;
- Tempo da música;
- Botões de reprodução;
- Botão de voltar;
- Fundo escuro inspirado na identidade visual do Spotify.

## 🎵 Informações utilizadas

**Artista:** Natiruts

**Álbum:** Verbalize

**Aplicativo utilizado como referência:** Spotify
